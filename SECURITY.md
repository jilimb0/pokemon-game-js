# Security Policy

## Reporting a Vulnerability

This is a static browser game. No user data is collected, stored, or transmitted. If you discover a security issue, please report it privately via GitHub Issues with `[SECURITY]` in the title.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x (latest) | ✅ |

## Security features

- Static site — no server, no database, no API
- No external dependencies (vanilla JS)
- All assets served from the same origin
